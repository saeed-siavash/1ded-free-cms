# Bundled template artwork

The design refresh uses 15 original images created with the built-in OpenAI image-generation tool. The CMS serves the resulting JPEG files locally from `public/starter-images/`. No image-generation tool, account, or remote image service is needed to install or run the CMS.

The original generated files are preserved in the maintainer's generation directory. Release assets are JPEG encodings at quality 82, with the original 1536 × 1024 pixel dimensions. No stock photographs or third-party marks were incorporated.

## Important use guidance

These are AI-generated illustrative samples. They are not photographs of the site owner's staff, premises, infrastructure, food, artwork, clients, events, or completed projects. Replace them with your own authentic images when that distinction matters. Do not present them as proof of qualifications, results, clinical practice, or owned facilities.

Edit an imported page in Pages, choose its hero/image/gallery section, and upload/select an image from the media library. Add accurate alternative text. Imports never replace images on existing pages.

## Actual website pages

All subject pages, including inner pages and sample articles, now include related artwork. Each visual theme supplies a default picture for an empty hero section, with a separately designed image composition. The 15 original images are shared where appropriate across the 23 designs; they are not 23 distinct photo sets.

In Templates & design, use **Refresh page pictures** beside an existing import to populate empty hero, image and gallery slots. Existing custom images, text, URLs, and page publication status are preserved. Changes are retained in history and require publication to reach the public site. Uncheck **Show related sample pictures in empty hero sections** to disable automatic fallback imagery.
